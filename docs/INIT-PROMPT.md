## 프롬프트

# Role
당신은 1990년대 MS-DOS 시절의 레트로 감성과 현대적인 터미널 UI(TUI) 아키텍처를 완벽히 이해하는 시니어 소프트웨어 엔지니어입니다.

# Goal
1990년대 한국 DOS 시대를 풍미했던 최정한 님의 전설적인 파일 관리 프로그램 **'Mdir (Mdir III)'**을 현대 OS(macOS/Linux/Windows) 터미널에서 완벽하게 동작하는 TUI 애플리케이션으로 구현해 주세요. 
기술 스택은 단일 환경에서 빠르게 실행 및 테스트할 수 있도록 **Python (`textual` 또는 `curses`/`rich`)**을 사용하고, 실행 스크립트 별칭(alias)으로 터미널에서 단 한 글자 `m`만 입력하면 즉시 실행되도록 패키징 구성을 포함해 주세요.

# Core Features & Philosophy (영상 핵심 고증 요소)

1. **시그니처 레이아웃 & 레트로 DOS 컬러 테마**
   - **배경 및 테두리**: 클래식 VGA 텍스트 모드 감성의 진한 파란색(`#0000AA`) 배경과 밝은 청록색/흰색 이중선 박스 드로잉 문자(`╔═╦═╗`, `║`, `╚═╩═╝`)를 사용한 테이블 레이아웃.
   - **다단 컬럼 뷰 & 듀얼 패널 전환**:
     - 기본 모드는 Mdir 특유의 한 화면 다단(Multi-column, 2~4열) 파일 리스트 뷰(파일명, 확장자, 크기, 날짜가 콤팩트하게 정렬됨)와 우측/하단의 시스템 및 디스크 정보 요약 영역.
     - `Tab` 또는 설정 키로 좌우 분할(Dual-pane) 모드로 즉시 전환 가능.
   - **한글(CJK) 완벽 지원**: 한글 완성형/유니코드 파일명이 포함되어 있어도 전각/반각 문자 너비(`wcwidth`)를 정확히 계산하여 테이블 테두리 선이 절대 깨지거나 밀리지 않아야 함.

2. **확장자별 색상 하이라이팅 (Color Coding)**
   - Mdir이 노턴 커맨더(NC)보다 사랑받았던 핵심 기능인 직관적인 파일 색상 구분을 구현:
     - 디렉터리 (`<DIR>`): 밝은 노란색 또는 흰색 굵게
     - 실행 파일 (`.exe`, `.com`, `.sh`, `.app` 등 및 실행 권한 파일): 밝은 초록색 (`#55FF55`)
     - 배치/스크립트 (`.bat`, `.cmd`, `.py`, `.js`): 밝은 노란색 (`#FFFF55`)
     - 압축 파일 (`.zip`, `.tar`, `.gz`, `.7z`, `.lzh`, `.arj`): 밝은 자홍색/마젠타 (`#FF55FF`)
     - 문서/텍스트 (`.txt`, `.md`, `.doc`, `.hwp`, `.json`): 밝은 하늘색 (`#55FFFF`)
     - 이미지/미디어 (`.jpg`, `.png`, `.mp3`, `.mp4`): 밝은 빨간색 (`#FF5555`)
     - 일반 파일: 밝은 회색 (`#AAAAAA`)

3. **Mdir 고유의 키보드 조작계 (단일 키 및 기능키)**
   - **이동 및 실행**: 방향키(`↑`, `↓`, `←`, `→`), `PgUp`/`PgDn`, `Home`/`End`로 커서 이동. `Enter` 입력 시 디렉터리면 진입(`..`은 상위 이동), 텍스트 파일이면 내장 뷰어 실행, 실행 파일이면 실행. `Backspace`는 상위 디렉터리로 즉시 이동.
   - **파일 선택 (Marking)**: `Space` 또는 `Insert` 키를 누르면 현재 파일이 선택(노란색 하이라이트 + `*` 표시)되며 커서가 자동으로 다음 항목으로 이동. 하단 상태바에 선택된 파일의 총 개수와 합산 용량 표시.
   - **단일 알파벳 명령 단축키**:
     - `C`: 파일 복사 (Copy) - 대상 경로 입력 또는 반대편 패널로 복사
     - `M`: 파일 이동 / 이름 변경 (Move/Rename)
     - `D` 또는 `Del`: 파일 삭제 (Delete) - 확인 팝업 표시
     - `K`: 새 디렉터리 생성 (Mkdir)
     - `V`: 내장 텍스트 뷰어 **'VV(보라)'** 모드로 파일 열기
     - `A`: 속성/정렬 변경 (이름순, 확장자순, 크기순, 시간순)
     - `Q` 또는 `ESC`: 프로그램 종료 (종료 시 마지막으로 탐색한 디렉터리 경로를 셸에 남기거나 출력하는 옵션 지원)
   - **빠른 첫 글자 점프**: `/` 또는 `Alt + 문자` 입력 시 해당 글자로 시작하는 파일로 즉시 커서 이동.

4. **필수 부가 유틸리티 내장**
   - **내장 텍스트 뷰어 ('VV' 오마주)**: 텍스트/코드 파일을 열었을 때 줄 번호, 인코딩(UTF-8, CP949 자동 감지), 퍼센트 표시줄, 검색(`/`) 기능을 갖춘 레트로 블루/그린 테마의 고속 뷰어 모달.
   - **디렉터리 트리 탐색기 (MCD 오마주)**: `F10` 또는 `T` 키를 누르면 디렉터리 구조를 트리 형태로 한눈에 보여주며 화살표로 빠르게 폴더를 점프할 수 있는 팝업 제공.
   - **압축 파일 내부 탐색**: `.zip`이나 `.tar.gz` 파일에서 `Enter`를 치면 압축을 풀지 않고도 일반 폴더처럼 내부 파일 목록을 탐색하고 추출할 수 있는 가상 폴더 기능.

5. **하단 정보창 및 Function Key 안내 바**
   - 하단에는 현재 경로(Path), 선택된 파일 수/크기, 현재 드라이브의 남은 용량(Free Disk Space) 및 메모리 상태를 표시.
   - 맨 아랫줄에는 초보자도 보고 누를 수 있도록 `F1:도움말 F2:이름변경 F3:보기(VV) F4:편집 F5:복사 F6:이동 F7:폴더생성 F8:삭제 F9:트리(MCD) F10:종료` 형태의 클래식 하단 바 배치.

# Deliverables
1. 즉시 실행 가능한 전체 소스 코드 (모듈화 또는 단일 실행 스크립트)
2. `requirements.txt` 및 터미널에서 `m` 한 글자로 실행할 수 있도록 `alias m=...` 및 종료 시 디렉터리 변경(cd)이 유지되는 셸 래퍼 함수(`m()`) 설정 가이드.

## 후속 요청

> P 로 출력된 화면이 있는데. 손봐줘.

테두리 `═` 가 `PPPP` 로 찍히던 문제 — ncurses 6.0 의 `rep` 시퀀스 버그. `disable_rep()` 로 해결.

## 구현에서 프롬프트와 다르게 정한 점

- 트리는 `T` / `F9` (F10 은 하단 바 안내대로 종료).
- 두 창 모드에서 `←` `→` 는 창 전환.
- 기술 스택은 칸 단위 제어가 쉬운 `curses` 를 택했다.
